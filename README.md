Laar RN

Simple Expo app to display Live GPS and Live Sales reports.

Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run ios # or: npm run android, npm run web
```

3. On first launch, paste your `X-Api-Key` (same key used for curl) and Save.

Notes

- API key is stored securely using `expo-secure-store`.
- Pull down on the list to refresh data.
